## 📖 Overview

**SATURO BOT V2** is a customizable Facebook Messenger bot
framework designed for group management, automation,
commands, events and various utility features.

The project is based on the Goat-Bot-V2 ecosystem and has
been customized with additional changes and improvements.

---

## ✨ Features

- ⚡ Fast command handling
- 🧩 Modular command system
- 👥 Group management
- 🛡️ Permission and role system
- 🔄 Event-based architecture
- 🌐 Multi-language support
- 📊 Dashboard support
- 💾 Database support
- 🎨 Custom reply and message design
- 🤖 Automatic command loading
- ⏱️ Command cooldown system
- 🔧 Easy configuration
- 📁 Custom command support
- 🔌 Extendable plugin-style structure

---

## 🚧 Requirements

Before running SATURO BOT V2, make sure you have:

- Node.js 22.x
- Git
- npm
- A supported database configuration
- Basic knowledge of JavaScript / Node.js
