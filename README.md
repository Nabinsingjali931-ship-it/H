🌟 About

SATURO BOT V2 is a customized Facebook Messenger bot based on the Goat-Bot-V2 ecosystem, enhanced and maintained by ANIK ISLAM SADIK.

✨ Features

- 🤖 Modular Command System
- 👥 Group Management
- 🛡️ Permission & Role System
- 🔄 Event Handling
- 💾 Database Support
- 🌐 Multi-Language Support
- 📊 Dashboard
- ⏱️ Cooldown System
- 🐳 Docker Support
- 🔧 Easy Customization

⚙️ Installation

1. Clone

git clone https://github.com/lazyanik/SATURO-BOT-V2.git
cd SATURO-BOT-V2

2. Install Dependencies

npm install

3. Configure

Configure the required settings in:

config.json
configCommands.json
fca-config.json

For detailed installation instructions:

cat STEP_INSTALL.md

4. Run

Follow the startup instructions provided in "STEP_INSTALL.md".
